# Phone layout and language

Five visible tabs keep the core loop simple: Map, Activities, Squads, Progress, and Profile. Create opens activity creation from the main screens. Use short screen titles, sentence case instructions, and labeled actions; avoid adding new names such as councils, sonar, or ghost beacons to the pilot.

Activities are plans. Squads are invite-only groups. Private lists choose an audience. Goals describe what someone wants to achieve; habits describe repeatable steps. Interested and Going remain separate, and neither enables location sharing.

Show avatars is available on Map and under Profile → Display. It hides photos and initials across this device while keeping names and live map dots. It does not change profile photo access for other people or revoke location sharing. The preference survives an app restart. Each user has an initials avatar until they upload a photo.

Phone content uses a single column, flexible rows, wrapping filters, and scrollable forms. Map height follows screen height. Navigation remains visible at the bottom. Browser checks cover 320, 375, and 390 pixel widths and avatar persistence; physical-device checks are still required for native maps, large system text, and keyboards.

The additional games, reels, organization hierarchy, public discovery, and automatic location sharing in the brainstorming notes are not part of this UI refinement. The pilot retains the existing permissions and core features.
